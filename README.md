# Cloudguard---AI
CloudGuard AI – Cloud Attack Path Prediction &amp; Risk Scoring System
Overview

CloudGuard AI is a desktop-based AI-powered system that models cloud infrastructure attack paths and calculates dynamic risk scores using graph analysis and machine learning.

Architecture

Frontend:

Electron

React

Tailwind CSS

Backend:

Python

FastAPI

NetworkX

Database:

Neo4j (Graph Database)

ML Engine:

XGBoost / Scikit-learn

Core Modules

Attack Graph Generator

Risk Scoring Engine

ML Prediction Engine

Visualization Dashboard

Recommendation Engine
